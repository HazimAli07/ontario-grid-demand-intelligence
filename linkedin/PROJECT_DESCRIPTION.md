# LinkedIn project entry

## Project name

Ontario Grid Demand Intelligence Lakehouse

## Description

Built an individual end-to-end analytics-engineering and machine-learning project using official IESO hourly electricity-demand reports. The solution implements reproducible ingestion, source lineage, Bronze-Silver-Gold data modelling, data-quality checks, dashboard-ready SQL, and a leakage-safe 24-hour demand forecast.

The verified local snapshot contains 40,056 hourly observations from January 2022 through July 28, 2026. On the final 1,417-hour chronological holdout, the gradient-boosted model achieved 6.28% MAPE and 0.755 R², reducing MAE by 39.3% compared with a same-hour-last-week baseline. I also built a polished Streamlit dashboard and an uploadable Databricks notebook that creates Delta tables for daily KPIs, load profiles, peak hours, and forecasts.

Tools: Python, SQL, pandas, scikit-learn, PySpark, Databricks, Delta Lake, Streamlit, Plotly, pytest, GitHub Actions.
